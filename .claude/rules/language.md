# Language Rules

These apply to every session and every department role.

- Everything in the repository is in English: code and its comments, commit messages, branch names, pull request titles, descriptions and review comments, rules, agent files, and everything under `docs/`, job notes and handoffs included.
- Everything written into the task tracker, once Tenon has one, is in English too.
- Text Tenon shows its users, such as prompts and messages an extension defines, is the one exception: it is written in the language it is shown in.
- A quotation that must stay exact, such as a task's acceptance criteria quoted in a brief, stays as written, inside quotation marks.
