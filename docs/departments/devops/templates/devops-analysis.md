# DevOps analysis

What a DevOps role returns as specialist, before the gate. PM passes it to the BA assistant and then to both halves of the gate.

```md
🤖 DevOps <role>: analysis for #<issue number> <task title>

**Touches:** <each launcher, workflow or variable the change would add or change, with paths, never a secret value>

**How:** <how the change would be built, in a few sentences, naming the design sections it follows>

**Tests:** <the tests that would prove each acceptance criterion>

**Other roles:** <changes needed in another role's part, and which role, or "none">

**Questions for the BA assistant, if any:**

1. <question>
```
