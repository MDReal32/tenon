# BA knowledge

Facts and lessons for reading tasks. Not rules: the rules are in [`RULES.md`](RULES.md).

## Facts

- The owner writes every task and answers every question.
- Tenon is a generic, extension-driven project generator. The engine knows nothing about languages or frameworks; everything a user sees comes from extensions speaking the Tenon Extension Protocol. The whole design is in [the design book](../../tenon.md).
- Tenon is at the design stage: no code exists yet. The [roadmap](../../06-project/01-roadmap.md) starts with M0, a contract spike that proves the protocol with tiny Python and TypeScript extensions.
- Items the design marks **[open]**, and the list under "Still open", are undecided. A task that depends on one needs the owner's decision first.
