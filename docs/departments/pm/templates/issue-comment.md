# Issue comment

What PM posts on the task's issue when its state changes: a step's verdict, questions that park it, a stop, or the PR. Short; the full record is in the PR description.

```md
🤖 PM coordinator: <one line: what happened, e.g. "Gate approved, work started" or "Parked: two questions">

<questions, if any, numbered, each answerable in a line or two>

Waiting on: <@MDReal32 | nobody>
PR: <link, if any>
```

A role's questions, such as [the BA assistant's](../../ba/templates/questions-for-owner.md), go in as the role wrote them, under PM's first line.
