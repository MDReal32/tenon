# PO knowledge

Facts and lessons for the gate. Not rules: the rules are in [`RULES.md`](RULES.md).

## Facts

- The owner writes every task as a GitHub issue and answers every fit question in its comments.
- [The design book](../../tenon.md) is Tenon's product vision as well as its design. Its promise to users: one engine that generates any kind of project, where every language, framework and default comes from extensions any author can write in any language.
- The roadmap is a sequence of thin vertical slices, M0 to M6. Work from a later milestone before an earlier one is done is a question for the owner, not an automatic rejection.
- Base gets nothing a community extension can't get. A task that gives Base or a first-party extension a private path into the engine contradicts the design.
